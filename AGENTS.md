# Publishing preference

The user wants changes to this garden published to its existing GitHub Pages website as part of the task, unless they explicitly request local-only work.

After validating site changes, commit the relevant files and push to `main` on `origin`. The Garden GitHub Actions workflow builds and deploys the site. Check that deployment succeeds and that the live page contains the changes before reporting publication complete.

# Public wording

Proofread all public-facing wording, including text supplied by the user. Correct spelling, grammar, and punctuation while preserving the intended meaning and the deliberate formatting of names and code. Do not assume the user's draft spelling is final.

Keep filter-bar labels lowercase. Name the visual category `visuals`, not `images`.

Use the shared green palette for selected controls, hover states, current navigation, and highlighted UI labels.

Preserve the loose, scattered card arrangement inspired by the Hydra garden. Uneven positions, natural heights, and small overlaps are part of its character. Responsive fixes should keep cards on screen and text readable, and keep headings and filters clear; do not replace the composition with a uniform grid.
