# Publishing preference

The user wants changes to this garden published to its existing GitHub Pages website as part of the task, unless they explicitly request local-only work.

After validating site changes, commit the relevant files and push to `main` on `origin`. The Garden GitHub Actions workflow builds and deploys the site. Check that deployment succeeds and that the live page contains the changes before reporting publication complete.
