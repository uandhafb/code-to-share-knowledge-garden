## About this meetup

In this first meetup, we made music and visuals with code using two web-based languages. **Strudel** is a live coding environment for music, and **Hydra** is a live coding video synth.

## Hydra

- A browser-based live coding environment for real-time video synthesis.
- Created by **Olivia Jack** in **2017**.
- Written in JavaScript; it compiles to WebGL shaders (GLSL) under the hood.
- Runs entirely in the browser, with no installation needed.
- Inspired by **analog modular video synthesizers**: you patch sources through transformations into outputs.
- Networked: Hydra windows can share their video streams with each other (WebRTC).

A first taste. Change a number, then press **Run**:

```hydra
noise(4).repeat(10, 10, 0.5, 0.5).pixelate(60, 30).colorama(-0.5).out()
```

### About Olivia Jack

Olivia Jack is a programmer and artist who works with open-source software, cartography, live coding and experimental interfaces. She has a background in computer engineering and first came to live coding while living in Bogotá, Colombia.

Besides Hydra, she has built other browser-based creative tools, including PIXELSYNTH, LiveLab, ghost-map (generative, temporary street maps drawn in the browser) and PIXELJAM, for live coding together.

### How Hydra code flows

Like a modular synth, every line of Hydra patches a signal from a source, through transformations, to an output:

1. [[category:hydra/source|Source]]: generates the signal (`osc`, `noise`, `voronoi`, `shape`).
2. Transformations: change the signal. [[category:hydra/geometry|Geometry]], [[category:hydra/color|Color]], [[category:hydra/blend|Blend]] and [[category:hydra/modulate|Modulate]].
3. [[category:hydra/output|Output]]: shows the signal (`.out()`).
4. [[category:hydra/patterns|Patterns & signals]]: make any value change over time.

Start with the [[category:hydra/source#rules-for-every-function|rules for every function]].
