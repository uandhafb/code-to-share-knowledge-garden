## Strudel: notes, scales, and effects

Open the [Strudel REPL](https://strudel.cc/). **Ctrl + Enter** plays or updates the code, and **Ctrl + .** stops it. On a Mac, both use **Control**, not Command. Each example below has an **Open in Strudel** link.

> **Try it #1 · 2 minutes:** write a pattern with your favorite sounds. Need a reminder? See [[strudel/sound|sounds]] and the [[category:strudel/mini-notation|mini-notation symbols]].

### First notes

`note("...")` plays pitches. You can write them as numbers or as letters:

| How | What to write | Example |
|---|---|---|
| numbers | 60 is middle C, +1 is the next key on the piano, +12 is one octave up | `note("48 52 55 59")` |
| letters | `c d e f g a b` | `note("c e g b")` |
| black keys | add `#` (sharp, higher) or `b` (flat, lower) | `note("c# eb f# ab")` |
| octaves | add a number: `c4` is middle C, `c2` is low, `c6` is high | `note("c2 e3 g4 b5")` |

A letter with no number plays octave 3: `c` is `c3`, which is 48.

**What is MIDI?** MIDI (Musical Instrument Digital Interface, 1983) is the language that keyboards, synths, and computers use to talk to each other. Every note is a number from 0 to 127, one per piano key, so `note("60")` in Strudel is MIDI note 60: middle C. See [[strudel/midi|MIDI numbers]] for the full table.

The same melody, three ways:

```strudel
note("48 52 55 59").sound("piano")
```

```strudel
note("c3 e3 g3 b3").sound("piano")
```

```strudel
note("0 4 7 11".add(48)).sound("piano")
```

`.add(48)` adds 48 to every number (0 + 48 = 48 = c3, 4 + 48 = 52 = e3…), so you think in "how many piano keys up from my starting note". Negative numbers go down: `note("-1 0 1 2".add(60))` plays b3, c4, c#4, and d4. On its own, `note("0")` is a C so low (about 8 Hz) that you can't hear it; that's why we add a starting note. More in [[strudel/add|add]].

`.sound()` works with notes too: `piano`, the synthesizer waves `sawtooth`, `square`, `triangle`, and `sine`, a double bass (`gm_acoustic_bass`), or a choir (`gm_voice_oohs`). See [[strudel/instruments|instruments]].

```strudel
note("c e g b").sound("<piano sawtooth gm_voice_oohs>")
```

The mini-notation symbols work with notes too. One note per cycle:

```strudel
note("<c a f e>").sound("piano")
```

> **Try it #2 · 2 minutes:** write a short melody with `note()`, using letters or numbers, then change the `.sound()`.

### Harmony and chords

A **melody** is notes one after another; you can sing it. **Harmony** is notes at the same time; they sound together and color each other. A **chord** is the building block of harmony, and a list of chords played one after another is a **chord progression**, like C Am F G.

A comma inside `[ ]` plays notes together. The same chord, three ways:

```strudel
note("[c3,e3,g3]").sound("piano")
```

```strudel
note("[48,52,55]").sound("piano")
```

```strudel
note("[0,4,7]".add(48)).sound("piano")
```

The **root** is the note that gives the chord its name. Count the piano keys up from the root to get the chord's **shape**:

| Chord | Shape | Symbol |
|---|---|---|
| major | 0,4,7 | `C` (also `CM`, `C^`) |
| minor | 0,3,7 | `Cm` (also `C-`) |
| diminished | 0,3,6 | `Co` |
| augmented | 0,4,8 | `Caug` |
| seventh | 0,4,7,10 | `C7` |
| minor seventh | 0,3,7,10 | `Cm7` (also `C-7`) |
| major seventh | 0,4,7,11 | `C^7` |

Any root works: `Am`, `F#m`, `Bb7`, `Eo`… Careful: `Cdim` and `C+` give an error; use `Co` and `Caug`. One shape, many chords (C, F, G, C):

```strudel
note("[0,4,7]".add("<48 53 55 48>")).sound("piano")
```

`chord("...").voicing()` picks the notes for you and arranges them so each chord moves smoothly to the next one, like singers in a choir: nobody jumps far. See [[strudel/voicing|voicing]].

```strudel
chord("<C Am F G>").voicing().sound("piano")
```

An **arpeggio** plays the notes of a chord one at a time. `n("...")` picks notes out of the voicing by number: 0 is the **lowest** note (not always the root), 1 the next one up, and so on. See [[strudel/arpeggio|arpeggio]].

```strudel
n("0 1 2 3 4 3 2 1").chord("<C Am F G>").voicing().sound("piano")
```

For a bass line, `.rootNotes(2)` plays only the root of each chord, in octave 2, and `.struct("x ~ x x")` gives it a rhythm. See [[strudel/root-notes|rootNotes]].

```strudel
chord("<C Am F G>").rootNotes(2).struct("x ~ x x").sound("gm_acoustic_bass")
```

> **Try it #3 · 2 minutes:** play chords, an arpeggio, and a bass line together.

```strudel
$: chord("<C Am F G>").voicing().sound("piano").gain(0.5)
$: n("0 1 2 3 4 3 2 1").chord("<C Am F G>").voicing().sound("sawtooth").lpf(1200).gain(0.4)
$: chord("<C Am F G>").rootNotes(2).struct("x ~ x x").sound("gm_acoustic_bass")
```

### Scales

A **scale** picks a few notes out of all the possible ones, so a melody sounds like it lives in one musical world. With `n("...")` and `.scale("...")`, the numbers become **steps** of the scale: 0 is the tonic, 1 is the next note of the scale, 7 is the tonic one octave up, and negative numbers go below. `"C:minor"` is the tonic, a colon, then the scale name; add an octave for lower or higher, as in `"A2:minor:pentatonic"`. See [[strudel/scale|scale]] for the table of scales.

```strudel
n("0 .. 7").scale("C:major").sound("piano")
```

The same numbers in different scales; listen to the mood change:

```strudel
n("0 2 4 <6 7>").scale("C:major").sound("piano")
```

```strudel
n("0 2 4 <6 7>").scale("C:minor").sound("piano")
```

```strudel
n("0 2 4 <6 7>").scale("C:iwato").sound("piano")
```

Chords in a scale: `[0,2,4]` is the tonic chord.

```strudel
n("<[0,2,4] [-2,0,2] [-1,1,3] [-3,-1,1]>").scale("C4:minor").sound("piano")
```

Playing together? Agree on a tonic and a scale first, and everything will fit. [More scale names](https://strudel.cc/learn/tonal/#scalename).

> **Try it #4 · 2 minutes:** write a melody in a scale.

```strudel
n("0 [2 4] <6 7> ~").scale("D:dorian").sound("piano")
```

### Effects

| Effect | What it does | Values |
|---|---|---|
| `.gain()` | volume | 0 is silent, 0.8 is the default, 1 is louder |
| `.room()` | reverb, like a big room | 0 is dry, 1 is a big room |
| `.lpf()` | low-pass filter: cuts the bright part | 200 is muffled, 5000 is bright |
| `.vowel()` | makes it sound like a voice | `"a"`, `"e"`, `"i"`, `"o"`, `"u"` |
| `.adsr()` | the shape of each note | `".1:.1:.5:.2"` |
| `.delay()` | echo | 0 to 1 |
| `.pan()` | left / right | 0 is left, 0.5 is the middle, 1 is right |
| `.speed()` | playback speed (pitch) | 2 is higher, −1 is backwards |

[[strudel/gain|gain]], [[strudel/room|room]], [[strudel/pan|pan]], and [[strudel/speed|speed]] are from Meetup #1. The new ones:

**[[strudel/lpf|lpf]]**, the low-pass filter, lets the low part through and cuts the bright part. A low number sounds muffled, like music through a wall:

```strudel
note("c2 c2 c3 c2").sound("sawtooth").lpf(sine.range(200, 2000).slow(4))
```

**[[strudel/vowel|vowel]]** shapes the sound like a mouth singing a vowel:

```strudel
note("c3 eb3 g3 bb3").sound("sawtooth").vowel("<a e i o>")
```

**[[strudel/adsr|adsr]]** is the shape of every note: **a**ttack (how long it takes to reach full volume), **d**ecay (how long it takes to fall to the sustain level), **s**ustain (the volume it keeps while the note lasts), and **r**elease (how long it takes to fade out).

```strudel
note("c3 e3 g3 b3").sound("sawtooth").adsr(".1:.1:.5:.2")
```

**[[strudel/delay|delay]]** with three values sets the amount, the time between echoes, and how many come back:

```strudel
s("bd rim").delay(".65:.25:.9")
```

> **Try it #5 · 2 minutes:** add effects to your melody.

```strudel
n("0 [2 4] <6 7> ~").scale("D:dorian").sound("sawtooth")
  .lpf(800).room(0.5).adsr(".05:.1:.5:.3")
```

### More than one pattern

`$:` plays each line as its own pattern, and `stack()` ties several patterns into one. See [[strudel/dollar|$:]] and [[strudel/stack|stack]] from Meetup #1.

> **Try it #6 · 2 minutes:** a bass line and chords in C minor. `.orbit()` gives each line its own effects, so the reverb on the chords doesn't spill onto the bass.

```strudel
$: n("0 [~ 0] <-3 -2> ~").scale("C2:minor").sound("sawtooth").lpf(sine.range(300, 1200).slow(4)).orbit(2)
$: n("<[0,2,4] [-2,0,2] [-1,1,3] [-3,-1,1]>").scale("C4:minor").sound("piano").room(0.6).gain(0.5).orbit(3)
```

## Hydra: color, blend, and modulate

Open the [Hydra editor](https://hydra.ojack.xyz). **Ctrl + Enter** runs the line you're on, **Alt + Enter** (**Option + Enter** on a Mac) runs a block, **Ctrl + Shift + Enter** runs everything, and `hush()` clears the screen. The full list of shortcuts, the sources, and the [[category:hydra/source#rules-for-every-function|rules for every function]] are in [[meetup:01|Meetup #1]].

> **Flashing lights:** some patches today change fast or flash. If you are sensitive to flashing images, look away or step back from the screen.

**Try it #1 · 2 minutes:** start from a [[category:hydra/source|source]].

```hydra
osc(20, 0.1, 1).out()
```

### Color

[[category:hydra/color|Color]] transformations keep every pixel where it is and change its value: how bright, how colorful, and which color.

| Function (defaults) | What it does |
|---|---|
| [[brightness]] `(0.4)` | adds light (negative = darker) |
| [[contrast]] `(1.6)` | darks darker, lights lighter |
| [[saturate]] `(2)` | how strong the colors are (0 = black and white) |
| [[hue]] `(0.4)` | turns all colors around the color wheel |
| [[colorama]] `(0.005)` | turns colors and brightness: wild rainbow bands |
| [[color]] `(1, 1, 1, 1)` | how much red, green, blue, and alpha to keep |
| [[invert]] `(1)` | the opposite colors, like a photo negative |

Careful: `brightness()` with nothing makes the image **brighter**, because the default is 0.4, not 0. Chain them; the order matters here too:

```hydra
osc(10, 0.1, 1)
  .rotate(() => Math.sin(time * 0.2))
  .brightness(-0.2)
  .contrast(2)
  .hue(() => time * 0.05)
  .out()
```

**Try it #2 · 2 minutes:**

```hydra
voronoi(7, 0.3, 1).colorama(3).invert(0).out()
```

### Blend

[[category:hydra/blend|Blend]] functions mix two images: `imageA.blendFunction(imageB, amount).out()`. Image A is the one you start with, before the dot; image B goes inside the parentheses, and it can be any source or a whole chain. Think of these as the mixer of your modular synth.

| Function (defaults) | The math | What you see |
|---|---|---|
| [[add]] `(B, 1)` | A + B | like two projectors on one wall: brighter |
| [[sub]] `(B, 1)` | A − B | B's light is taken away: darker |
| [[mult]] `(B, 1)` | A × B | a stencil: black in B hides A |
| [[diff]] `(B)` | \|A − B\| | where A and B are the same: black |
| [[blend]] `(B, 0.5)` | a crossfade | like a DJ mixer: 0 = A, 1 = B |
| [[layer]] `(B)` | B on top | like a sticker: A shows through B's transparent parts |

**Careful with `sub`:** every image has an invisible fourth value, its transparency (alpha), and `sub` takes that away too. In the Hydra editor, `osc(10, 0.1, 1).sub(shape(4, 0.4)).out()` is all black. `.color(1, 1, 1, 0)` keeps the second image's colors but sets its alpha to 0, which cuts a clean black square hole:

```hydra
osc(10, 0.1, 1).sub(shape(4, 0.4).color(1, 1, 1, 0)).out()
```

For `layer`, most sources are not transparent, so cut the top image with [[luma]]: its dark parts become transparent.

```hydra
shape(4, 0.3, 0.01).color(1, 0, 0).layer(shape(6, 0.2, 0.01).color(0, 1, 0).luma()).out()
```

**Try it #3 · 2 minutes:**

```hydra
voronoi(7, 0.3, 1).colorama(3).mult(shape(4, 0.5, 0.01)).out()
```

### Modulate

Geometry like `rotate(0.5)` moves every pixel by the same amount. [[category:hydra/modulate|Modulate]] lets image B decide, pixel by pixel: `imageA.modulate(imageB, amount).out()`. The result is liquid, organic, glitchy distortion. It's like FM in a synth, but for images.

| Function (defaults) | It's like… | What you see |
|---|---|---|
| [[modulate]] `(B, 0.1)` | `scroll` | wavy glass, liquid |
| [[modulate-rotate\|modulateRotate]] `(B, 1, 0)` | `rotate` | each part turns differently |
| [[modulate-scale\|modulateScale]] `(B, 1, 1)` | `scale` | each part zooms differently |
| [[modulate-scroll\|modulateScrollX / Y]] `(B, 0.5, 0)` | `scrollX` / `scrollY` | pushed sideways, or up and down, by B |
| [[modulate-repeat\|modulateRepeat]] `(B, 3, 3, 0.5, 0.5)` | `repeat` | a grid scattered by B |
| [[modulate-kaleid\|modulateKaleid]] `(B, 4)` | `kaleid` | a kaleidoscope that melts |
| [[modulate-pixelate\|modulatePixelate]] `(B, 10, 3)` | `pixelate` | B decides the pixel size |
| [[modulate-hue\|modulateHue]] `(B, 1)` | (no twin) | pushed by B's colors |

```hydra
osc(10, 0.1, 1).modulate(noise(3), 0.1).out()
```

**Try it #4 · 2 minutes:**

```hydra
voronoi(5, 0.3, 1).saturate(3).modulate(noise(2), 0.2).out()
```

### Putting it all together

In the Hydra editor, put the cursor inside the block and press **Alt + Enter** (**Option + Enter** on a Mac):

```hydra
voronoi(5, 0.3, 1)
  .modulate(noise(3), 0.2)
  .kaleid(6)
  .colorama(0.1)
  .diff(
    osc(30, 0.1, 1)
      .rotate(() => time * 0.1)
      .mult(shape(100, 0.6, 0.3))
  )
  .out()
```
