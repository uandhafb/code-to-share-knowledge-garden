## How it works

A `~` takes up a step, like any sound, but plays nothing.

## Example

```strudel
s("bd ~ sd ~")
```

## Try this

Rests make room for the other sounds:

```strudel
s("bd ~ ~ sd ~ bd ~ ~")
```
