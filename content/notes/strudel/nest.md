## How it works

Square brackets fit several events into a single step. Here, the second step is split into two snares.

## Example

```strudel
s("bd [sd sd] cp hh")
```

## Try this

Nests can go deeper:

```strudel
s("jazz [rim [jazz casio]] ~ casio")
```

A rest and a kick, sharing one step:

```strudel
s("bd sd [~ bd] sd")
```
