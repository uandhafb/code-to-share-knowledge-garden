## How it works

Each name separated by a space is one step, and all the steps share one cycle. Four steps at the default tempo last half a second each; six steps last about a third of a second each.

## Example

```strudel
s("bd sd cp cp")
```

## Try this

Six steps: denser, but still one cycle:

```strudel
s("bd sd cp cp rim casio")
```
