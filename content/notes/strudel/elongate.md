## How it works

`@` sets how long a step is compared with the others. In `"bd@3 sd"`, `bd` is three times as long as `sd`, so it takes 3/4 of the cycle.

## Example

```strudel
s("bd@3 sd")
```

## Try this

`bd` gets 4/5 of the cycle and `sd` gets 1/5:

```strudel
s("bd@4 sd")
```
