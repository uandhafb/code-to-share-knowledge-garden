Mini-notation is the text inside the quotes. Each pattern fills exactly one cycle, so more sounds make it denser, not longer.

| Symbol | Name | Example | What you hear |
|---|---|---|---|
| space | sequence | `"bd sd cp"` | three steps in one cycle |
| `~` | rest | `"bd ~ sd ~"` | silence on steps 2 and 4 |
| `[ ]` | nest | `"bd [sd sd]"` | step 2 split in two |
| `< >` | one per cycle | `"bd <sd cp>"` | `sd`, then `cp`, then `sd`… |
| `*` | faster | `"bd hh*4"` | four hi-hats inside one step |
| `/` | slower | `"bd sd/2"` | `sd` only every other cycle |
| `!` | replicate | `"bd!3 sd"` | the same as `"bd bd bd sd"` |
| `@` | longer | `"bd@3 sd"` | `bd` takes 3/4 of the cycle |
| `?` | maybe | `"hh*8?"` | each hi-hat has a 50% chance |
| `\|` | random pick | `"bd [sd\|cp\|rim]"` | a new pick every cycle |
| `,` | layers | `"bd sd, hh*4"` | both play at the same time |
| `.` | groups | `"bd sd . hh hh hh"` | the same as `"[bd sd] [hh hh hh]"` |
| `{ }` | polymeter | `"{hh cp, lt bd sd}"` | layers that drift apart |
